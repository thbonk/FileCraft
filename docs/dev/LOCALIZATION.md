# Localization

FileCraft ships in English, the development language, and German.

## Where strings live

- `FileCraft/Resources/Localizable.xcstrings` holds all user-visible strings of the app.
- `FileCraft/Resources/InfoPlist.xcstrings` holds localized Info.plist values such as usage descriptions.
- The privileged helper returns error codes only; the app maps them to strings in its own catalog.

## Workflow

1. Change user-visible text in code, written in English.
2. Run `xcodebuild -exportLocalizations -project FileCraft.xcodeproj -localizationPath <folder> -exportLanguage de` to add new keys to the catalogs and mark unused ones as stale.
3. Add the German values, remove stale keys and add translator comments to short or ambiguous keys.
4. Run `LocalizationCoverageTests`: it fails on missing or unfinished German translations, stale keys, changed placeholders and count strings without plural variants.

## Rules

- Write the English text in code and never build user-visible text by concatenation.
- Use plural variants for every count-dependent string.
- Format dates, numbers and byte counts with `FormatStyle`.
- Add a translator comment to every key whose meaning is not obvious from the English text.
- German text follows the glossary below and Apple's macOS German terminology for system concepts.
- Claude drafts the German translations; the project owner spot-checks the German UI before release.
- Changing a glossary term requires the project owner's approval.

## German conventions

Decided by the project owner on 2026-10-30:

- Address the user formally with "Sie", for example "Möchten Sie den Papierkorb entleeren?".
- Menu titles that open a dialog end with an ellipsis character without a preceding space, for example "Einstellungen…".
- Quote file names and other inserted text with guillemets, for example "»Bericht.pdf« kann nicht gelöscht werden.".
